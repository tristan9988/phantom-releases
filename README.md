# Phantom

Builds of the Phantom client for friends. This repository holds release files only.

## Install

1. Install Java 11 or newer if you don't have it (for example [Adoptium Temurin](https://adoptium.net/)).
2. Download **[launcher.jar](https://github.com/tristan9988/phantom-releases/releases/latest/download/launcher.jar)**
   and put it anywhere, for example your Desktop.
3. Double-click it.

That's it. Every time you start `launcher.jar` it checks for a new Phantom build, downloads and
verifies it if there is one, and opens the dashboard. RuneLite is kept up to date by the dashboard
itself. You never need to download the launcher again.

## Writing scripts

Download **[Phantom-Script-Kit.zip](https://github.com/tristan9988/phantom-releases/releases/latest/download/Phantom-Script-Kit.zip)**,
unzip it and open the folder in [VS Code](https://code.visualstudio.com/). It has autocomplete for
the whole API, examples, and tasks to test a script offline and install it into Phantom. The kit
updates itself whenever Phantom updates. The same kit is also on Phantom's **Scripting** page.
